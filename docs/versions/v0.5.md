## Mode 3 - Review / Recovery

QA-Post:

- Initial result: Fail.
- Blocking finding:
  - Rotated JPEGs with EXIF orientation were not handled before description metadata was stripped.
  - This would make common phone photos export sideways after clear/rewrite metadata removed the orientation tag.
- Recovery:
  - Replaced direct `image::open(...).to_rgba8()` export decode with `ImageReader::into_decoder()`.
  - Read decoder orientation, decoded the image, and applied orientation to pixels before watermark rendering.
  - Added regression coverage for a JPEG with EXIF orientation `6`, verifying output dimensions become visually upright.
- Re-verification:
  - `cargo test --manifest-path src-tauri/Cargo.toml applies_jpeg_exif_orientation_before_stripping_metadata -- --nocapture` passed.
  - `cargo test --manifest-path src-tauri/Cargo.toml` passed with 14 tests.
  - `cargo check --manifest-path src-tauri/Cargo.toml` passed.
  - `pnpm build` passed.

## Post-MVP Stabilization - Preview And Placement

PM:

- User-facing priority is precise, fast watermark positioning. The app should feel like
  a small desktop utility, not a slow render queue.

Architect:

- Keep Rust as the final export renderer, but keep preview interaction on the frontend.
- Store placement as relative coordinates and an anchor. `custom` coordinates may sit
  outside the image bounds so the renderer can naturally clip overflow.

QA-Pre:

- Dragging beyond the right or bottom edge must not wrap text or snap back.
- Bottom presets mean the watermark box bottom aligns to the image bottom.
- Opacity must update the preview immediately.
- Template save/load must preserve watermark, export, and metadata settings together.

Main Chat:

- Removed inactive Fit and 100% preview buttons.
- Expanded position presets to top/center/bottom by left/center/right.
- Changed drag behavior to update the overlay directly during pointer movement, then
  sync the editor state.
- Removed frontend and Rust renderer clamps that forced custom positions back into the
  image bounds.
- Prevented live watermark text wrapping with `white-space: nowrap`.
- Synced the custom export prefix from the active watermark text.
- Added Tauri drag/drop import for image files and folders.
- Added per-image Remove controls in the import queue.
- Added font family selection to the watermark style and Rust export DTO.
- Added export loading overlay and completion/failure notification.
