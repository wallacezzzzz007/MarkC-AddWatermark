# v0.3 - Single-Image Export Proof

Status: Completed

## Mode 0 - Intake

PM:

- v0.3 proves the full value chain for one selected image: current watermark settings become a real output file.
- Batch export remains v0.4.

Architect:

- Rust becomes authoritative for final rendering.
- Frontend sends selected source path and watermark DTO to one export command.
- Export writes to a default sibling folder named `Watermark export`.

QA-Pre:

- Source image must never be overwritten.
- Output dimensions must match source dimensions.
- Preview/export placement should be close enough for v0.3 proof.
- Existing output names should not be overwritten silently.

UI/UX:

- Enable the export button only for real imported images.
- Show exporting/success/error state and output path.

Main Chat:

- Implement single-image export and verify with generated temp images before moving to v0.4.

## Mode 1 - Proposal

PM:

- Recommended task: export the selected image with the current text watermark.
- Why now: this proves the product's core promise before batch complexity.
- Acceptance criteria:
  - User can export the selected image.
  - Exported image has the same dimensions as the source.
  - Exported image includes the watermark.
  - Source file is not modified.
  - Default output folder is `Watermark export`.
  - Default file name is `{name}_watermark.{ext}`.

Architect:

- Design impact:
  - Add export DTO shared conceptually with frontend watermark state.
  - Add Rust renderer/exporter modules.
  - Add `export_selected_image` IPC command.
- Modules affected:
  - `src/lib/ipc.ts`
  - `src/types/export.ts`
  - `src/components/ControlPane.tsx`
  - `src-tauri/src/commands/export.rs`
  - `src-tauri/src/domain/export.rs`
  - `src-tauri/src/processing/renderer.rs`
  - `src-tauri/src/processing/exporter.rs`
- IPC plan:
  - `export_selected_image(request: ExportSelectedRequest) -> ExportResult`

QA-Pre:

- Risks:
  - Font rendering differs from preview.
  - JPEG encoding changes quality more than expected.
  - Output file collision overwrites an existing export.
  - Watermark coordinates are mapped incorrectly for bottom anchors.
  - Alpha blending differs between PNG/JPEG.
- Required tests:
  - Export PNG and compare dimensions.
  - Export JPEG and compare dimensions.
  - Confirm source modified timestamp unchanged.
  - Confirm output path is in `Watermark export`.
  - Confirm collision creates a numbered filename.

UI/UX:

- Output section becomes active for selected non-QA assets.
- Export button shows idle/exporting/success/error.
- Keep batch controls out of v0.3.

QA-Post:

- Pending.

Main Chat:

- Final proposed next step: implement single-image export and run QA.

## Mode 2 - Execution
